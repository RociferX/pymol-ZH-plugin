# 安装与显示故障排查

## 安装后仍是英文

1. 确认选择的是 Release 附件 `pymol_zh_cn-0.3.2.zip`，不是 GitHub 的 `Source code` 压缩包。
2. 打开 `Plugin → Plugin Manager`，检查 `pymol_zh_cn` 已安装，且 `startup` 已勾选。
3. 在插件菜单的 `中文显示 / Chinese Display` 中选择“启用中文显示”。更新旧版本后需重启一次。
4. 如果电脑装有多个 PyMOL，确认安装插件的窗口和以后使用的图标属于同一个环境。
5. 查看控制台加载错误；将错误原文及版本信息附到[安装问题反馈](https://github.com/RociferX/pymol-ZH-plugin/issues/new?template=installation.yml)。

插件需要 Qt 图形界面，命令行无界面模式不会显示中文控件。

## 插件目录没有写入权限

在安装器询问安装目录时选择当前用户可写的插件目录。可在插件管理器的设置中查看或添加用户插件搜索路径，然后重新安装。将管理员安装的 PyMOL 与用户插件目录配合使用，避免为安装插件修改程序目录权限。不同版本的管理器按钮名称可能有差异。

## 更新后版本没有变化

安装新 ZIP 后关闭并重新打开 PyMOL，再查看 `插件 → 中文显示 / Chinese Display → 关于中文显示插件`。仍显示旧版本时，在插件管理器检查是否有多个搜索目录包含同名 `pymol_zh_cn`；保留所需的一份安装，再重启。

## 中文变成方框、缺字或乱码

先检查系统是否安装中文字体。Windows 可使用微软雅黑，Linux 可安装 Noto Sans CJK，macOS 可使用苹方。安装字体后重启 PyMOL。使用远程桌面时，确认查看的是实际交互桌面。

仍异常时，请提供系统、PyMOL/Qt 版本、显示缩放比例、当前字体或主题、出问题的窗口截图。若复制出的原始英文正常，而中文显示缺字，优先检查字体。

## 字体被截断、按钮重叠或窗口超出屏幕

记录系统缩放和窗口大小，尝试调整窗口大小；将最短操作步骤和截图提交到[翻译与布局反馈](https://github.com/RociferX/pymol-ZH-plugin/issues/new?template=translation.yml)。当前实际桌面检查主要覆盖 Windows 的 100% 和 200%；第三方主题、其他平台及自定义字体可能产生不同布局。

## 有些文字还是英文

命令、参数键、格式标识、对象名、路径、序列、代码示例及用户输入按原文显示。未知文字和第三方输出不会自动机器翻译。对于界面中的漏译，反馈英文原文、所在菜单/窗口、版本和截图即可。

## 查看原始帮助或错误

在插件菜单选择“恢复英文显示”，即可查看、复制原控件中的英文诊断。中文菜单不会改变命令行语法，例如教程中的 `show cartoon` 仍按英文输入。

## 临时停用或卸载

- 当前窗口停用：选择“恢复英文显示”。
- 停止自动加载：插件管理器取消该插件的 `startup`，然后重启。
- 卸载：在插件管理器卸载 `pymol_zh_cn`，然后重启。

## 反馈时提供版本

插件版本见“关于中文显示插件”，PyMOL 版本见其关于窗口。也可在 PyMOL 命令行输入：

```text
print(cmd.get_version())
```

提交信息前检查路径、文件名和结构截图中是否含不打算公开的内容。
